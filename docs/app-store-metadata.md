### 概要（4000文字以内）
```
写真の色をスポイトで拾って、手持ちの絵具でどう混ぜれば近い色が作れるかを逆算するアプリです。

■ 減法混色で予測する
混色は RGB の平均ではなく、絵具の吸収と散乱を扱う減法混色（Kubelka-Munk）で計算します。白を混ぜたときの淡まり方、補色を混ぜたときの濁り、明度の落ち方がそのまま出るので、画面の予測が実際の絵具に近づきます。

■ ホルベインのカタログ全色から
油絵具111色、透明水彩18色から配合を探します。色名・品番・顔料記号・乾燥日数・透明性・耐光性・20ml参考価格まで、公式カタログの記載どおりに見られます。

■ スポイトとルーペ
写真の上に指を置くと、指の少し上にルーペが出て、その場所の色を正確に読みます。拾った色と予測色の色差（CIEDE2000）も数字で出ます。

■ 5色で作る／仕上がり
パレットから5色を選べば、その5色だけで配合を探せます。「仕上がり」では、写真全体をその5色で塗ったらどう見えるかを確かめられます。

■ 端末のなかだけで
写真の読み込みも色の計算も、すべて iPhone のなかで行います。写真を外部へ送ることはありません（通信は広告の読み込みのみ）。

※ 予測はカタログの色見本をもとにした近似です。乾き方や艶、下地で見え方は変わります。
※ iPhone（iOS 17.0 以上）・縦向き。
```
（582文字）

アプリ本体は何も収集しない。広告SDK（Google Mobile Ads）分だけを、サードパーティの広告目的として申告する。

| データの種類 | 収集 | 使途 | トラッキング |

| 識別子（端末ID） | する（Google Mobile Ads SDK） | サードパーティの広告 | しない |

## 9. 未対応・提出前に判断がいること

1. **広告IDが Google のテスト用IDのまま**（`Sources/BannerAdView.swift` の `adUnitID` と `Info.plist` の `GADApplicationIdentifier` が `ca-app-pub-3940256099942544` 系）。このまま審査に出すと広告はテスト広告のままで、収益も出ない。本番のアプリID・ユニットIDへ差し替えるか、いったん広告を外して出すかを決める。差し替えは Swift 側の変更なので、このタスクでは触っていない。
2. **アプリ内課金（広告非表示）が ASC 未登録**。商品を作らないまま提出すると、アプリ内の「広告を消す」が「準備中」で押せない状態になる。審査で「機能していない課金導線」と見られる可能性があるため、商品登録して提出するか、導線ごと外すかを決める。
3. **6本同時提出のスパム判定（ガイドライン4.3）**。同じ開発者から同じ分野のアプリをまとめて出すため、機能の違いが伝わるよう、概要とレビューメモで「何をするアプリか」を明確にしている。スクリーンショットもアプリごとに別の画面にすること。
4. **`PrivacyInfo.xcprivacy` は同梱済み**（追跡なし・UserDefaults の利用理由 CA92.1）。
5. 予測は近似である旨を概要に明記済み（景表法の観点でも「必ずこの色になる」とは書かない）。
